# Documentation Synchronization Rule

Whenever any new feature, API endpoint, schema, component, or architectural change is introduced or modified:

1. **`README.md`**: Update the features list, commands, and endpoint directory.
2. **`TECHNICAL_PLAN.md`**: Update the technical specification, database models, request lifecycles, and architectural diagrams.
3. **`BEGINNER_GUIDE.md`**: Update with baby-step explanations written in simple, clear language with long sentences and real-world analogies explaining *why* and *how* the new feature works.
